# Подготовка к КР-1 по курсу «Хранилища данных» (ВШБ ВШЭ)

Сайт для подготовки к контрольной работе №1: проектирование ядра хранилища (3НФ) и витрин данных.

**Сайт:** https://barsik033.github.io/dwh/

Внутри: азы с нуля, алгоритм решения КР, разбор учебного кейса, теория (ядро, витрины по Кимбаллу, архитектура), SQL-паттерны, ловушки, три пробные КР с таймером, тест и карточки терминов.

Один самодостаточный файл `index.html`, без сборки.
